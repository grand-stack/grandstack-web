# grandstack-web

A small React client for [grandstack-server](../grandstack-server): browse and search movies, view cast and directors, and add a movie. Operations are typed end to end by GraphQL Code Generator.

Run it with the rest of the stack from the [grandstack](../grandstack) repo (`docker compose up --build`, then open http://localhost:3000). See [AGENTS.md](AGENTS.md) for development and codegen.
