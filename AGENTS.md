# AGENTS.md: grandstack-web

React + Vite client for grandstack-server. Uses urql with typed operations generated by GraphQL Code Generator (client preset).

## Run
- Whole stack: `cd ../grandstack && docker compose up --build`. Web at http://localhost:3000, GraphQL at http://localhost:4000/graphql.
- Dev server: `npm install && npm run dev` (needs the server running; set `VITE_GRAPHQL_URL` to change the endpoint).

## Change or add operations
1. Write the query or mutation inside a `graphql(`...`)` call (see `src/pages/*.tsx`), importing `graphql` from `src/graphql/generated`.
2. Start the server, then run `npm run codegen`. It validates every document against the live schema and fails on unknown fields. Output in `src/graphql/generated/` is committed; do not edit it by hand.
3. Run `npm run typecheck`.

## Notes
- `VITE_GRAPHQL_URL` is fixed at build time. The browser calls the server directly, so the server's `CORS_ORIGIN` must include the web origin (default http://localhost:3000).
- Title search uses `contains`, which is case-sensitive.
- Creating movies is unauthenticated until the auth phase.
- Keep `graphql` on 16.x to match the server.
